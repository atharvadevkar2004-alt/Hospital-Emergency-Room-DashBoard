# 🏥 Hospital Emergency Room Analytics Dashboard

## 📌 Project Overview
This project is an Interactive Emergency Room Analytics Dashboard developed in Microsoft Excel.  
It transforms raw hospital data into meaningful insights using Power Query, Power Pivot, and DAX.

## 🎯 Project Objective
To analyze hospital emergency room performance by tracking:

- Total Patients
- Admission vs Non-Admission Status
- Patient Wait Time (Under 30 Minutes)
- Department Referrals
- Patient Demographics
- Monthly Trends

## 📊 Key Insights
- Percentage of patients treated within 30 minutes
- Admission rate analysis
- Department receiving highest patient referrals
- Monthly patient trends
- Gender & Race distribution

## 🛠 Tools Used
- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Data Visualization

## 📂 Files Included
- DashBoard.xlsx – Final interactive dashboard
- Hospital Emergency Room Data.csv – Raw dataset
- Screenshot.png – Dashboard preview image

## 🚀 How to Use
1. Download the Excel file.
2. Open in Microsoft Excel (2016 or later).
3. Use slicers to interact with the dashboard.
